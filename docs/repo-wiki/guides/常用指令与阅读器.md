# 常用指令与阅读器

| 目标 | 可以对 Agent 说 |
| --- | --- |
| 梳理产品 | 先整理产品规则和验收，必要时提问，暂不实现。 |
| 压力测试 | 检查这份方案的关键歧义与领域边界，把结论写回适当资料。 |
| 技术规划 | 按已确认 Spec 编写执行计划。 |
| 实施或恢复 | 按已确认计划实施，或恢复当前任务。 |
| 查询知识 | 解释安装保护和恢复机制，指出来源。 |
| 维护知识 | 核对这次源码变化，更新受影响专题。 |
| 阅读器 | 打开、重启或停止这个项目的 Wiki 阅读器。 |

本仓没有业务前后端生命周期扩展，不生成无用 dev-servers；构建是维护命令。Runtime 构建/检查见根 AGENTS，浏览器阅读器与 Runtime 分别构建。四个日常 Skill 位于规范包 assets/skills，路径由 root manifest 定位。

阅读器由 lumine-knowledge 的[阅读器管理指导](../../../skills/lumine-harness/assets/skills/lumine-knowledge/references/reader.md)管理，核实当前项目归属后复用或启停，并报告本次真实地址。不要按端口批量停止其他项目进程；HTTP 可达不等于导航、搜索和图解全部可用。它无需连接模型或启动业务服务，直接阅读/检索 Markdown 时也无需浏览器。

需要终端检索时，在本仓运行 `./.lumine/cli wiki query "问题"`；查看目录用 `./.lumine/cli wiki map`，结构检查用 `./.lumine/cli wiki check`。扫描和检查不会自动撰写知识。没有专用 wiki stop/restart/status 命令时，由 Agent 按进程归属处理，不能编造命令。真实宿主事件能力须单独核实。

实施或恢复可以直接说明目标与现有成果，Agent 按 [lumine-run](../../../skills/lumine-harness/assets/skills/lumine-run/SKILL.md) 维护并绑定对应任务；无需用户手工填写任务 JSON。要查看已记录任务，可以使用 `./.lumine/cli task show <taskId>`，核对记录用 `task check <taskId> --json`，参数是任务 ID。创建、并发更新与当前会话绑定的详细操作只在 Skill 维护；绑定不代替授权。
