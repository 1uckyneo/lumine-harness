# 宽内容桌面阅读复验

## 范围

本轮只验证 1440×1000、浏览器缩放 100% 的桌面阅读。按用户明确产品范围：Repo Wiki 是桌面阅读器，不要求窄屏使用；窄屏不在产品要求、交付目标或验收门槛内。既有窄屏与真实 200% 观察仅保留为历史诊断。此记录不代表整个 AC-009 或人工接受已完成。

## 发现与复验

18 列表格在修复前继承 `overflow-wrap:anywhere`，760px 容器内的首单元格 35 个字符拆成 14 行，整表高 451.5px，桌面也难以阅读。规范 CSS 修复并重新构建、同步后，同一宽表高 84px，首单元格保持 1 行；内部内容宽 4740px、容器宽 760px，可以局部滚动 3980px 到达最后一列。页面宽仍为 1440px。

真实横向滚轮输入使表格和代码各自滚动 500px，页面横向位置均保持 0。1,245 字符代码保留单行格式并局部滚动；995 字符路径在正文内完整换行。新增两列短表没有横向溢出；正文导航落点可见，七个主要按钮可见且未禁用。
