选取的实际表格及展开的 Mermaid 源码在 200% 时仍能自然容纳，因此不将它们描述为已触发横向溢出。作为补充，仅在既有隔离宽内容样例执行一次同样的桌面 200% 状态：表格容器宽 686px、内容宽 4740px、首单元格 1 行；代码内容宽 10039px。真实横向滚轮使代码与表格各自滚动 250 CSS px，页面横向位置保持 0；995 字符路径完整换为 14 行。未重跑视口矩阵。

402 个 Wiki 正文与持久状态文件在检查前后内容哈希一致。记录的项目请求均为 GET；未调用模型、修改知识正文或业务子仓。实际项目的临时截图仅用于本地视觉检查，截图、页面快照及临时浏览器 profile 均已删除；公开证据不包含私有路径、远端、账号、页面名称或会话标识。
