## 4. Plugin 包在无外网请求条件下冷启动

冷启动取 Plugin wrapper 分发包，在临时空工程创建并应用提案 `554fc67a-c51c-4739-bfe9-35be11da3e91`。没有选择 Adapter；安装结果为 `applied`，finalize 结果为 `complete`。已安装 manifest 与 wrapper manifest 的 SHA 均为 `668ac45ef5f6e7e89bff503c6fe9555176390b8c2cfe09cf8e92907fd6ed8c76`，reader 的 SHA 同为上面的 `fa56c759…`。

目标工程无 `node_modules`，读取前无 Wiki 缓存；浏览器初始 cookies 和 origins 数量均为 0，service worker 为 0，通过浏览器协议禁用缓存。读取后仍无 Wiki 缓存。安装器只创建空锁目录；记录中的 Node 18 socket 监测没有观察到连接尝试。

真实浏览器冷启动后：

- 长文第 100 段可见，既有 Mermaid 实际生成 1 个 SVG；没有用占位图代替。
- 填写 `Readable text` 得到 `Showing 1 / 1 results`，结果和章节入口存在。
- 产品读取／绘图／搜索阶段记录 38 个请求和 38 个响应，响应均为 200，来源只有本地服务；1024px 追加读取后累计 40 个请求和响应，仍仅本地来源。
- 记录的外部产品请求为空、主页面 `pageErrors` 为空。外部地址负控被请求拦截器拒绝，导航报 `ERR_BLOCKED_BY_CLIENT`，确认拦截器实际生效。
- 1024 × 768 的临时长文 body 与 document 宽度均为 1024，article clientWidth 与 scrollWidth 均为 728，第 100 段仍可读；fixture 没有表格或长路径，不能补足这些样本要求。

“无外网”在本证据中指浏览器只允许本地请求、外部请求被拒绝；没有物理断开宿主网络。没有 Adapter 的安装可以完成本地 finalize，但不能据此证明正式父仓真实宿主 Hook 已执行。该历史构建的结果也不替代最终构建与真实宿主的验证。

JSON 已移除重复的逐请求响应数组，保留实际请求数量、响应状态计数、唯一请求路径与来源，以及正文／SVG／搜索／负控和缓存证据；没有保存机器绝对路径、截图私有路径或 SVG 长文本。

独立验证使用纯文本 fixture：`graph LR` 架构关系、`sequenceDiagram`、`flowchart`、`stateDiagram-v2` 和 `erDiagram`，另有语法错误图与带远程 `click` 的拒绝样本。它们是验收样本，不作为工程知识事实写回正式 Wiki。

最终验证的 `reader.js` SHA 为 `6c8b1db63ba94c62b7a9c16e2d1a9394ad3bcbcbb67f72f807d200cc54c2a0d8`；相关 TypeScript 与 manifest 指纹保存在 JSON。该结果与第 4 节 `fa56c759…` 历史冷启动分别记录。

### 五类交互与首次缺口

逐类实际打开图解、点击放大／缩小／适合窗口／重置、使用真实鼠标拖动平移，以及方向键移动和 `+`／`0` 键。五类 `controlsPassed`、`sourceMatches`、`copiedSourceExact` 均为 true；复制引用分别为 `five-diagrams#图ID`。Escape 后焦点返回各自打开按钮。

首次版本没有主动复制 Mermaid 源码的按钮，保留了五类的首次观察。新增中英文按钮后，五类英文复制读取真实剪贴板，值与输入源码相同。另使用 Chrome CDP `Browser.setPermission` 将 `clipboard-write` 真正设为 `denied`，由 `navigator.permissions` 确认权限状态；未通过 DOM monkeypatch 伪装失败。中英文拒绝路径均显示正确提示与完整的手动复制文本，关闭后焦点返回复制按钮，原图保留；恢复权限后状态为 `granted`。

### 深链与前置布局变化

首次 ER 新加载深链的焦点虽然是 `er`，目标 top 为 907.515625，超过 720px 视口，图仍在载入、未生成 SVG。前置图解高度变化使目标离开可视区。修复后在网络与布局稳定时记录：

| 代表图 | 焦点 | 稳定 top（px） | 目标 SVG |
|---|---|---:|---:|
| 架构 | architecture | 20 | 1 |

| 流程 | flow | 27.359375 | 1 |

真实 mouse wheel 后，ER top 由 19.515625 变为 -430.484375。再在正文前注入 420px 的临时 DOM spacer，top 仍为 -430.484375，说明用户已经滚动后，前置高度变化不会将位置抢回锚点。spacer 随后删除；这一步是布局故障注入，没有修改 Wiki 知识。

首页返回时保留早期 top=368.515625 与自动布局稳定后的 top=28.515625；刷新后 top=19.515625。URL、ER 焦点和 SVG 保持。最终记录没有观察到首帧 ResizeObserver 导致定位提前取消。

### 局部失败与主动导出

语法错误图和远程 `click` 样本只使自身失败，说明和原始 Mermaid 保持可读、可导出；对应 SVG 导出禁用，其他五图完整。没有请求示例远程地址。只将临时 fixture 的错误文本改为有效 Mermaid 后，顶栏刷新恢复 SVG 与 SVG 导出，原正文、其余五图和 URL 保持。

整个补验序列留下 14 个主动导出文件：6 个 SVG（包含修正后错误图）、7 个 Mermaid 和 1 个 Markdown。Mermaid 与各次输入原文相等；Markdown 与当前 fixture 正文逐字相等。它们跨越首次错误源码导出、修正后 SVG 恢复与最终交互阶段，不将所有文件描述为同一轮瞬时生成。

6 个 SVG 均可解析，包含图名、状态、正文 revision、文档和图 ID；revision 与当时当前文档 SHA 一致。逐文件安全检查没有发现 `script`／`foreignObject`／`image`／`a`、事件属性、`href`、远程／data／file CSS URL、机器路径或临时 URL。JSON 只保留文件指纹、元信息与审计结果，不保存长 SVG 内容或截图私有路径。

### 网络与知识文本边界

最终五类套件记录 240 个浏览器请求，全部为当前回环服务的 GET；外部请求、页面异常与请求失败均为零。权限、布局和局部恢复套件同样没有外部请求或页面异常。后续验证禁用了 CLI 更新检查；浏览器观察不能外推为所有宿主进程都不联网。

fixture 知识目录与 `.lumine` 只留下 Wiki Markdown、project/root JSON 三个文本文件，没有图片或预览缓存作为知识真源。PNG 是浏览器 QA 截图，SVG 是用户动作明确触发的导出，两者均作为验收产物单独保留。

正常知识流程的文本约束由规范 Skill／CLI 与源码约定支撑；本轮也通过受保护 prepare/apply 实际写回了 Wiki Markdown，见 [源仓知识复评与事务](源仓知识复评与事务.md) 和 [旧引用与图解恢复回归](旧引用与图解恢复回归.md)。这组证据支持静态约束与所列真实文本更新，不将 240 次浏览器 GET 视为全部知识创建、更新、查询链已执行，更不据此推出所有流程不生成图片或不调用模型的运行结论。

验证仅覆盖本地 Chromium、代表性小图与隔离 fixture，未覆盖全部 Mermaid 语法、全部浏览器或父仓所有真实图解。独立浏览器已关闭，4338 服务正常退出且没有剩余监听；其他验证服务未被停止。
