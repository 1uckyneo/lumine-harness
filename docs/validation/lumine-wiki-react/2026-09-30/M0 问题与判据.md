# 知识复核的预先问题与判据

固定于 2026-09-30 M0；先保留问题和判据，再进行本轮正文修订与答案评审。源仓与父仓各自作答，不能用构建或检索命中代替语义检查。

## 源仓

1. 从嵌套 Git 目录触发命令或宿主事件时，如何选择 Harness 根？根身份、仓库来源身份与 Runtime 所在位置分别由什么决定？迁移中断时应怎样处理？
   - 判据：给出根声明与显式 `--root`、最近有效根、仓库登记、运行资源分离；不把最近 Git 根或目录名猜测当成项目身份；说明部分迁移的限制并回到源码核实。
2. watched scope 内出现新文件但没有精确来源引用时，如何判断已由现有主题解释、确有新增能力或暂缓？以后来源改变时旧判断还能否直接复用？
   - 判据：扫描只报线索，主题范围和文件版本进入可恢复处置；理由可查看且随相关输入变化失效；正文由 Agent 核实后撰写，不能凭文件新增自动全库重写。
3. 人类搜索超过六条时，如何继续看结果？Agent 查询有哪些预算，章节与来源怎样定位？
   - 判据：明确浏览器分页与 `hasMore`，CLI 六卡与字符预算保留；结果绑定稳定片段，非 Wiki 提案不当作现状；遇到不足可改用目录与源码。

## `ai-conv-plus-workspace` 父仓

1. 三个 Git 边界分别承载什么？客户端与后台管理端是否同一应用？Go 重构源码、历史联调与当前部署能各自证明什么？
   - 判据：正确区分父仓、Vue 客户端、Go 服务与其后台管理端，保留独立版本；开发源码与旧联调不被推断成当前生产行为。
2. 图片任务 SSE 断开、页面刷新和主动取消时，怎样只更新原会话的原消息？何时无法精确恢复？
   - 判据：会话、消息、任务身份分开；精确任务查询与原历史回退；不重发生成；受理前缺身份、来源失败与取消失败保留真实不确定性；本地离页不等于服务端取消。
3. 文字聊天附图在模型拒绝时是否可以静默切换模型或退回纯文字？
   - 判据：核对客户端上传、请求字段和拒绝反馈；不以界面文案或历史样本代替当前源码；图片生成任务与文字附图不混同。
