## 行为与边界

- 打开时优先复用归属明确的本项目服务；缺少服务时调用现有 `wiki serve`。
- 支持显式 Harness 根、指定端口或系统分配端口，使用真实返回地址。
- 停止和重启前核实进程；使用原终端或已确认 PID 的温和信号，不误停其他项目。
- 明确宿主保活、HTTP 探测、页面刷新与服务重启的区别。
- 直接阅读 Markdown 和 Agent 检索无需服务；不虚构独立 stop/restart/status 命令，不新增后台守护或模型服务。
