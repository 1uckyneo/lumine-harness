# Agent 驱动 Repo Wiki 改造交付

Lumine Harness 的知识组织、检索、写入保护、阅读器、四个日常 Skills、中英文说明、三态协议和迁移已经实现并在源仓自用。未提交、推送或发布。

## 源仓交付

- 8 篇实际知识页，60 个稳定章节、12 个 Mermaid 图解，覆盖配置与根、多仓身份、工作流与证据、停止策略、Adapter 差异、Wiki、阅读器、采用迁移及构建分发。主要机制和限制已核对来源，详见[独立语义审阅](独立语义审阅.md)。
- 知识地图依据项目组织目录，章节卡片复用 Markdown，浏览器绘制 Mermaid；模型负责理解和撰写，程序只辅助检索、观察和保护性保存。
- 查询不强制扫描全仓、不向模型注入整库；本机观察凭据缺失或来源根缺失时保守报告，来源未变与语义审阅分开。
- 新建、拆页、目录分组、双向关系、增量维护、候选冲突与中断恢复已支持。迁移与日常 Runtime 分离，提案后新增旧格式资产会被重新盘点，不能静默覆盖。
- WORK_STATUS 为 done／continue／blocked；文本和结构化报告共用标准化、预算与去重。诊断完成不新增修复授权，Codex 不可观察的 Skill 读取不会伪装成缺失读事件或已观察。
- 中英文 README 保留语言切换、skills.sh、Agent Harness 与项目 Harness 互补定位和跨会话工程资产价值，并对齐实际知识能力。

## 验证结果

源码和正式分发测试各 202 项：201 通过、1 项既有跳过、0 失败。类型、Runtime 构建一致性、Skill 包、Plugin 同源同步通过，日志见[runtime](runtime/)。

正式 Node 18 分发在无缓存、无源码依赖、无模型、非回环网络被禁的隔离副本中可读、可搜、可绘图。实际页面验证知识树、正文目录、章节卡片、来源行号、关系、窄屏键盘和图查看器；错误图与坏页不会阻断其他正文。专项截图只作为验证证据，不属于知识生产。

当前项目同步安装同一版本并建立 29 篇主要模块知识。两个不继承对话的新 Agent 对照回答同样 12 问，均能定位来源；自主组选择了 Wiki 和源码，也暴露代码生成回滚说明过窄的问题。核实后增量写回，第三个新上下文能获得新增区别并继续提出具体边界。原答案、修订与复查分别保存，不声称一次建库即保证无遗漏，也不宣称未经同口径测量的速度或 Token 优势。
