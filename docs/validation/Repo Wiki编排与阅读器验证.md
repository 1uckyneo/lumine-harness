## 同日质量复核与修订

首轮的“演化”验证主要证明事务机制，不能代替 Agent 自主发现知识问题的能力。本次另开不含实现对话背景的维护 Agent，分别处理英文批量导出工具和中文多仓任务工具。两组均从现有首页、实际源码与适用规则出发，更新摘要、正文、流程图和导航；由未参与写作的 Agent 独立复读并回查来源。

- 英文样本从过期的一次性导出，改为开始、逐批读取与同进程接续，明确游标推进、批次丢失及进程重启的限制；保留数字字符串人工备注及完整令牌要求。独立审阅发现“批量限制”链接落点缺少数值，修正后再审通过。
- 中文样本改正无限重试与不支持暂停的旧说明，解释三次上限、排队时暂停及恢复回排队；拆分用户操作与安全阅读路径。原安全身份、章节入口与人工经验保留，只有已批准的术语作等价更正。代码未实现的命令、存储及认证边界如实记录，没有把实现缺口改成规范许可。
- 两组公开变更事务、结构／编排／存储／任务检查通过；业务源码与批准决定的哈希未变。候选章节与图同名时整组写入被保护性拒绝，修订候选后重用原包完成。

这是两组受控样本上的独立 Agent 维护证据，不是真实 SDK 用户或长期使用证明。主执行者曾提供 task 数据合同入口帮助；语义判断答案未提供。执行暴露的 coverage 版本字段、任务 scope 类型和 review 指纹获取说明已补入双语维护资料，不能把此次过程描述为完全无需接口帮助。

阅读器本轮改为默认收起来源，用资料原题或准确说明代替内部编号；操作随界面语言切换，资料不因界面切换而被翻译。完整 Markdown 来源提供渲染阅读和原文两种视图；局部来源不扩大行范围。来源有真实深链接，重载和前进后退可恢复面板。首页减轻技术目录密度，主要功能和安全入口仍直接可达。

实际 Chromium 检查了中文场景页、历史设计资料的 Markdown／原文切换、重载、前进后退及英文控件保留中文原题。独立源码审查发现同文件全文与局部来源会使语义锚点误选较短引用，已修正并加入回归；同时纠正了文件名压过有意义来源说明的回退顺序。未把这些观察作为业务系统运行验收。
