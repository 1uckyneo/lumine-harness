# Repo Wiki 业务发现与查证设计

关联产品方案 lumine-wiki-product-experience。本轮隔离样例以实际阅读器验证，评审以真实正文、文档清单和来源为输入。主题采用暖纸色、深色字与低饱和陶土强调，优先保证中文正文、可辨识的路径和查证后的阅读连续性。

| 路径 | 布局与交互 |
| --- | --- |
| 首次进入 | 项目总览先呈现读者可以做什么。突出业务或核心能力，导航按理解、开发与运行、查找与核实组织 |
| 理解模块 | 先概括角色和任务，主流程与例外进入正文。流程图可适配、放大并阅读相同事实的文本 |
| 搜索 | 支持标题、别名和正文。保留命中章节、状态、可继续浏览与无匹配反馈 |
| 核实 | 从正文或图打开来源，查看上下文或问题限制。关闭后可回到打开处 |
| 失败 | 空结果、单图失败、断线、来源待判断和冲突分别显示可采取的动作 |

网页原位、原生客户端原位、独立原型和图片探索是可选载体。此样例局限于知识阅读，无业务写入，设计结论回到现有 Spec。实际内容和宿主运行验收另有证据。
