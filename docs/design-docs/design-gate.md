# 设计判断与确认范围

Agent 根据产品 Spec、已有设计与实际页面判断是否需要视觉或交互设计，并给出依据。无需设计时建议直接编写 Exec Plan；需要设计时，先由用户确认产品方向与设计范围，再制作可审阅材料，包括适用的 HTML 原型。

设计材料说明所覆盖的页面、交互和状态，并关联产品 Spec。材料形式服务于待解决的问题，不要求固定附件套件；复用适用且已确认的设计，不因改名或排版重复制作。

设计完成后由人确认，再将有效的行为、场景和验收变化写回 Spec，保留设计附件引用。补充后的 Spec 再由人确认，才进入 Exec Plan；设计确认本身不授权进入 Run。完整的交接规则由[阶段交接](../../skills/lumine-harness/assets/skills/lumine-plan/references/stage-handoff.md)维护。

确认记录指向实际材料、范围与用户决定。Agent 自评、`approved` 字段、工具检查通过或早期笼统实施意愿都不能替代确认。已确认的同一范围不重复询问；Run 内可核实设计一致性，无需为验证单独取得确认。
