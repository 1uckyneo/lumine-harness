# Repo Wiki 阅读体验设计

关联产品方案：[Repo Wiki 知识体系与 React 阅读体验](../product-specs/Repo%20Wiki%20知识体系与%20React%20阅读体验.md)（`lumine-wiki-product-experience`）。[HTML 原型](Repo%20Wiki%20阅读体验原型.html)使用源仓真实长文片段演示桌面项目首页、正文查证和搜索；仅示例文章、来源及搜索结果实现了部分交互，其余卡片用于观察布局。它是设计材料，不能作为 React 实现或人工使用验收证据。

## 设计决定与范围

2026-09-29，用户在看到初版 Spec 与“进入四种状态设计”的交接问题后，明确委托 Agent 自行确定简洁、易读、美观的设计和色系，不要求单独审阅设计，并要求继续产出 Exec Plan；同时明确 `ai-conv-plus-workspace` 父项目 Repo Wiki 属于本轮交付。此决定仅覆盖本设计与规划，不授权实施、提交或发布。

2026-10-08，用户明确将窄屏使用场景移出产品范围。本设计据此面向桌面阅读，不要求移动布局、窄屏抽屉或独立中屏验收；保留 1440px 桌面、键盘操作及桌面浏览器 200% 缩放目标，不新增最小窗口宽度承诺。原型保留的自适应样式可用于桌面窗口调整与缩放，不构成窄屏或移动支持承诺。

同一阅读器分别服务 Lumine Harness 源仓和该多仓父项目。项目名称、主题和知识正文来自各自已登记的项目资料；界面不固化任一项目的目录结构。阅读主路径按“项目首页 → 主题／搜索 → 正文 → 就近来源”组织。Spec、Plan 与知识维护使用次级入口，保留直接链接。

## 色彩、字与空间

采用暖白与深绿，状态色只在需要读者行动的位置出现。颜色同时配文字或图标，不能单独表达状态。以下对比值按所列前景与背景计算，供实现校验；实际浏览器仍需复核。

| 用途 | 前景／背景 | 对比值 | 使用方式 |
|---|---|---:|---|
| 正文 | `#24302D`／`#FFFFFF` | 13.67:1 | 长文、标题与关键结论 |
| 次级文字 | `#52635B`／`#FFFFFF` | 6.37:1 | 摘要、时间和辅助说明 |
| 强调 | `#185C43`／`#FFFFFF` | 7.92:1 | 链接、当前项和主操作 |
| 警示 | `#805010`／`#FFF6E7` | 6.37:1 | 来源变化但影响待核实 |
| 错误 | `#973D38`／`#FFF0EE` | 6.23:1 | 已知失效、冲突和请求失败 |

画布 `#F7F8F5`、内容面 `#FFFFFF`、边界 `#DCE4DE`、轻强调底 `#EAF3ED`。不使用大面积渐变、毛玻璃或过多卡片阴影。字体使用系统中文与英文字体栈，避免外部字体和离线依赖。

- 正文 17px／1.75；阅读列最大 760px。标题依次约 32px、24px、19px，层级靠字号与留白表达。导航、按钮和状态说明至少 14px；可点击区域尽量达到 44px。
- 1440px 桌面使用约 240px 知识树、最多 760px 正文、约 190px 本页导航；桌面浏览器放大到 200% 时，可收起次要侧栏，但知识目录和本页导航仍可访问。仅代码块、宽表格和图解自身横向滚动，页面不整体溢出。
- 空间采用 8px 节奏：段间约 16–20px，章节间约 36–48px，正文内来源入口紧随对应章节或图解。长路径允许换行，代码保留等宽并局部滚动。

## 三个关键状态

| 状态 | 首要内容 | 次级内容与交互 |
|---|---|---|
| 项目首页 | 已确认项目名、简短简介、搜索、总览入口与知识地图主题 | 有历史时可继续阅读；根地址仍留在首页，显式深链优先 |
| 正文查证 | 标题、简要结论、必要的来源／语义警示和连续长文 | 复制引用是便捷操作；来源在对应章节就近打开详情，关闭后恢复正文滚动与焦点；本页导航跟随阅读位置 |
| 搜索 | 单列结果显示主题、命中章节、保留条件和否定的片段 | 可继续查看更多可靠结果；筛选折叠但已生效条件可见且可清；默认仅搜当前项目 Wiki，全体文档须显式切换 |

卡片为可选中、可复制的 HTML 文本，图解仍以 Mermaid 文本为知识真源。桌面鼠标与键盘使用相同的文档身份与深链；阅读位置属于项目和文档，不跨项目混用。

## 异常和可访问性

| 情况 | 用户看到的下一步 |
|---|---|
| 尚未建库或主题内容不全 | 已有正文照常可读；说明缺少的主题，提供可复制的继续整理指令 |
| 搜索无可靠结果 | “未找到相关知识”；可修改关键词、查看目录或复制调查问题 |
| 服务断开或加载失败 | 保留已读内容与位置，说明连接失败并提供重试；重试不宣称来源已经重新核实 |
| 来源不可读取、内容有冲突或图解失败 | 在相关内容附近提示具体状态；正文和其他图继续可读，Mermaid 源码可查看 |
| 剪贴板或本地存储不可用 | 显示可手动选择的引用文本；基本阅读仍可用 |

搜索、目录、正文、来源面板和图查看器支持键盘访问；焦点有明显轮廓，`Esc` 关闭浮层后回到触发按钮。状态文案区分“来源有变化，影响待核实”与“解释已失效”。中英文界面使用相同层级和可访问行为，切换界面语言不改正文语言。

## 与 Spec 和实施的边界

本设计选择了视觉 tokens、布局及已有产品规则的呈现方式，没有新增模型服务、编辑功能或知识审批阶段。根地址首页、显式深链优先、搜索继续查看、来源就近查证及项目状态隔离均已在 Spec 中定义；Spec 仅需链接本材料并明确本轮目标父项目。React 组件、状态库、API 变化和构建分发由 Exec Plan 决定。真实浏览器的 1440px 桌面、桌面浏览器 200% 缩放、键盘、长文与中英混排验收在实施后单独留证。已有窄屏观察保留其历史范围，不作为当前交付要求。
