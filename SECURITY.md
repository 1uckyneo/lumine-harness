# Security

## Reporting Issues

Open a private advisory or contact the repository maintainer through GitHub if you find a security issue.

## Operational Safety

This package can create, replace, or migrate AI workflow files in a target repository. Review the migration proposal before allowing writes, and inspect diffs before committing any adopted target.

Do not add secrets, tokens, private project paths, or customer data to skill files, templates, generated docs, examples, or issue reports.
