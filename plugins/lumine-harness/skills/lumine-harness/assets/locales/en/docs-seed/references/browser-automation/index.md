# Browser verification

Prefer browser tools already available in the environment. Verify real pages, material actions, relevant network outcomes, and necessary persistence/recovery against the user's goal. HTTP 200 or an existing screenshot is not capability acceptance.

Record date, page/environment scope, actions, results, and coverage limits. Do not export sensitive sessions into public records; respect authorization for business mutations.

Repo Wiki scanning, updates, and queries use text only, not screenshots supplied to vision models. Screenshots for dedicated UI verification are evidence, not inputs for knowledge cards, summaries, or diagrams, and are outside the routine maintenance pipeline.
