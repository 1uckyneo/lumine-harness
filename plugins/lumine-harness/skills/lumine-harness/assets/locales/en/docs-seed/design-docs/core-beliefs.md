# Design principles

- Understand the person's task before arranging information and actions.
- Put current conclusions before history, make primary actions clear, and give actionable next steps after errors.
- Use text, layout, and interaction to convey hierarchy; diagrams explain relationships rather than replacing prose.
- Reuse verified components and conventions while preserving genuine state, permission, and lifecycle differences.
- Design material explains intent; real browser and business evidence establish implementation outcomes.
