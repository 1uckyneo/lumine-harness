# Design material

Keep concrete visual and interaction proposals here. Read the related Spec and existing approved material, then use lumine-design as needed. Filenames may be Chinese or English; choose HTML prototypes, explanations, flow diagrams, or external references for their actual purpose.

- [Design decisions](design-gate.md): when a decision is needed and how its scope is recorded.
- [Design principles](core-beliefs.md): reading, interaction, and real verification.

Do not create a fixed directory tree or attachment bundle for every task. The Spec links designs, the Plan maps implementation, and validation records hold runtime evidence.
