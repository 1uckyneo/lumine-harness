# {{title}} Component Map

## 本文件用途

把设计稿中的页面区块映射到目标项目可实现的组件、API、状态、权限和非目标视觉细节。没有这份 handoff，复杂页面不得直接进入实现。

## Handoff 规则

- HTML 模式：从 `prototypes[]` 指向的 HTML 区块映射到真实组件和数据来源；单页面也是一个数组项。
- Hybrid 模式：先把选中的图片方向转成页面结构，再映射组件。
- Image 模式：只能探索视觉方向，不能单独作为实现输入。

## 区块映射

| 原型区块 | 目标实现位置 | 组件/库 | 数据来源/API | 状态/权限 | 不实现的视觉细节 |
| --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |

每个页面一个 `component-maps/<page-id>.md`，并在 `DESIGN.md` 的 `prototypes[]` 中登记。

## 通过标准

- 每个关键区块都有实现组件和数据来源。
- 用户可见文案不包含占位、开发提示或代码注释式文案。
- 明确哪些视觉细节只是原型表达，不要求真实实现。
