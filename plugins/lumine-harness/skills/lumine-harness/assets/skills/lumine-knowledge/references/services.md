# 项目服务扩展

采用时检查真实启动入口、脚本、已有 Skill、端口与健康检查。先复用项目能力，缺失且项目需要日常服务操作时生成共享项目扩展；不默认绑定语言、框架、包管理器、端口或操作系统。不把业务服务、Wiki 阅读器、数据库、MCP、容器与部署默认归为一个动作。

扩展只记录完成本项目操作所需的合同：

| 项目 | 必须明确的内容 |
| --- | --- |
| 触发与对象 | 自然语言用语、对应服务与 start/restart/stop/status；歧义按上下文澄清，不连带操作其他对象。 |
| 启动事实 | 仓库相对 cwd、真实命令、已有工具与配置变量名、参数优先级、健康检查及启动副作用；不保存敏感值。 |
| 实例归属 | 可复用和可停止的归属证据；停止前复核进程身份，未知端口占用报告冲突，不按进程名或端口批量杀。 |
| 生命周期 | 启动中继续查询不重开副本；失败给出可行动下一步；并发写入和中断恢复保护受控实例。 |
| 本地状态 | 状态、日志、非敏感恢复参数放已忽略本地位置；来源与项目身份可核实，不执行记录中的任意命令。 |
| 权限与验收 | 安装工具、改配置、迁移数据、部署各按真实授权；其他项目曾有的全局安装授权不能继承。监听／健康通过与登录、业务验收分开。 |

实现可用现有脚本、CLI 或轻量管理脚本，按当前项目需要选择，不为生成通用框架扩大范围。实际执行内容留在扩展目录，Wiki 操作指南只解释并引用；根 AGENTS 提供短入口。验证复用、归属、端口冲突、启动失败和停止边界，以及适用平台的真实生命周期；模拟或静态检查不能冒充实机结果。环境不足时保留可用入口、说明未验证范围。
