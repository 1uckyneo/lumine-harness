# Parallel coordination

Use workers when independence and benefit justify them, without a fixed headcount or role bundle. Explore unclear boundaries read-only before assigning exclusive file owners.

Task packets specify objective, relevant inputs, owned writes, read-only/forbidden sets, acceptance, stopping conditions, and reporting scope. One writer owns a file at a time. Workers do not modify shared Plans, rules, or knowledge state unless explicitly assigned.

Implementation and independent investigation can proceed in parallel. Integrate shared changes and apply knowledge state serially; verify real operation after relevant implementation is integrated. Review actual source and evidence rather than inferring deployment or acceptance from a worker's completion report.
