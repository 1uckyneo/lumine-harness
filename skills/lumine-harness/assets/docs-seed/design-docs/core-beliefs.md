# Core Beliefs

## 后台和业务工具体验

- 优先让用户快速定位信息、比较数据、完成重复操作。
- 视觉风格服务于可读性和稳定性，不做无业务意义的装饰。
- 表格、表单、弹窗、批量操作和导入导出结果必须状态清楚。

## 页面原型

- 复杂后台页面默认 HTML 原型。
- 客户审美要求高或风格不明确时，可使用当前可用的图像生成能力先探索视觉方向，再转 HTML 原型、component map、handoff 和 design_data；能力不可用时使用 HTML 原型或记录人工步骤。
- handoff 和 design_data 是模型生成的实现上下文；用户确认源仍是 `DESIGN.md`、HTML 原型和截图。
- 图片不能直接作为复杂页面实现输入。
