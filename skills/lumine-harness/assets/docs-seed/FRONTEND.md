# Frontend Taste

本文件属于可选 Frontend 模块；只有目标工程包含用户界面或用户明确需要 UI 约束时生成。

适用于用户可见 Web、移动端、后台管理、弹窗、表格、表单和导入导出结果。

## 硬规则

- 不出现代码注释式、占位式、开发提示式或未清理备注式文案。
- 不把字段 key、权限码、英文枚举值直接暴露给普通用户。
- 空态、错态、加载态、权限不可见/不可用和危险操作确认必须能被用户理解。
- 后台工具优先信息密度、可扫描性、稳定布局和重复操作效率。

## 禁止词扫描

检查明显问题词：`TODO`、`FIXME`、`mock`、`placeholder`、`待开发`、`开发中`、`测试文案`、`这里填写`。

## Design Handoff

需要设计确认的页面必须从 approved `DESIGN.md` 的 `prototypes[]` 进入实现。单页面也是数组里只有一个页面项，必须逐页读取 HTML、截图、component map、handoff 和 design_data。
